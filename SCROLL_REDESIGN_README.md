# SNAPBOTS scroll-led homepage redesign

This version replaces the generic orbital/AI-style hero with an editorial engineering-studio direction and a scroll-led process story.

## What changes as you scroll
- The process section has four stages: Discovery, Prototype, Validation, Delivery.
- The active stage changes as each stage enters the center of the viewport.
- The copy, progress indicator and custom-built schematic visual animate between stages.
- The homepage uses responsive layouts and respects reduced-motion preferences.
- Existing routes, content data, forms, account/admin structure and Firebase integration have not intentionally been removed.

## Run locally
Open a terminal in this folder (the folder containing this file and the root `package.json`), then run:

```bash
npm ci
npm run dev
```

Open the localhost URL printed by Vite. Do not run these commands from the parent folder.


## AgiAI launch feature
The homepage now includes an editorial AgiAI launch section with an original CSS botanical illustration, restrained scanning motion, image-led workflow copy, and a contact link for launch updates. The plant illustration is explicitly labelled as illustrative, not a real diagnosis. Launch messaging is set to Dussehra 2026 as requested.
